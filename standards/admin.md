# 管理后台 / CRUD / 工作台

- 先判断简单记录编辑还是复杂业务工作台。简单 CRUD 可对话框；多区块、子资源、多步审批优先既有独立页面/抽屉模式，不一刀切。
- 菜单、路由、权限与 API 同步，但不自动写数据库菜单 seed；未知权限 key 不发明。
- 列表避免逐行 N+1；分页/筛选进入合适的 URL 或持久状态，保存后保留上下文，末页删除处理页码回退。
- 提交使用字段 allowlist，服务端只读字段不回传。输入/提交/刷新分别有 loading 与失败恢复。
- 可逆低风险 Switch 可直接保存并失败恢复；危险/不可逆操作单独确认，不把一种交互推广到所有状态按钮。
- 子资源独立归属校验。媒体删除需要 staged 语义时，只在主记录保存成功后删除既有资源；取消不误删已存文件。
- 预览/下载依项目能力和权限决定；不能把某项目“禁止下载”推广为所有系统禁令。
- 导入模板、parser、校验、进度和审计需要一致；不要在 UI 临时重写一套业务导入规则。
