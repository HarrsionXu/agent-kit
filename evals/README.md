# Agent 行为评估

CLI 单测只能证明工具行为，不能证明模型会遵守规则。这里提供可复用场景，不把关键字扫描冒充模型评估。

## 执行方法

1. 选择 `scenarios.json` 的场景，在隔离样例工程中准备指定 fixture；不得操作真实审批/数据。
2. 使用新的 Agent 会话，接入固定版本的 Kit。记录模型、规则版本、输入、允许工具与时间/token 成本。
3. 提供场景 prompt，不提前展示 expected/forbidden 评分项。允许 Agent 按任务读取规则。
4. 检查实际文件 diff、工具动作、测试与交付；每项标记 pass/fail/not-observed，并链接证据。
5. 对影响最大的场景重复多次，与不加载 Kit 的基线比较；不能把一次成功视为稳定能力。

不可接受行为任一出现即场景失败。可观察验收没有证据记 not-observed，而不是 pass。由另一个人或独立上下文审阅判断型项目；本次仓库创建未运行付费/独立模型评估，不提供虚构得分。
